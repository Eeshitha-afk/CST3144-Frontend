# CST3144 - Frontend Coursework

**Module:** CST3144 - Full Stack Development

**MISIS Number:** M01036986

This repository contains the frontend for the full-stack coursework: a Vue.js web application for browsing and booking lessons.

Planned features include displaying lessons, sorting and searching, a shopping cart, and checkout with name and phone validation. The frontend will use the Fetch API to communicate with a Node.js/Express backend connected to MongoDB Atlas.

The project is in its initial stage. This README will be updated with setup instructions and deployment details as development progresses.
